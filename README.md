Parking Calculator – Advanced

A responsive parking fee calculator built using HTML, Bootstrap 5, and JavaScript.

 Features

- Vehicle number and type selection
- Date and time pickers
- Automatic parking duration calculation
- Parking fee calculation based on vehicle type
- Input validation
- Interactive alerts using SweetAlert2
- Responsive user interface

 Technologies Used

- HTML5
- Bootstrap 5
- JavaScript
- SweetAlert2
- Bootstrap Icons

 Parking Rates

| Vehicle Type | First Hour | Additional Hours |
|---|---:|---:|
| Bike | Rs. 50 | Rs. 30 |
| Car | Rs. 100 | Rs. 50 |
| Van | Rs. 150 | Rs. 75 |
| Bus | Rs. 200 | Rs. 100 |

 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter the vehicle details and calculate the parking fee.
